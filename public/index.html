◆ DataGuard for Excel

Finds duplicate IDs, placeholders, numbers stored as text, spelling variants, totals that don't add up and more, in any Excel table. Everything runs inside Excel: your data is never sent anywhere.

Download the add-in file (manifest.xml)

Install in Excel on the web (easiest)

  1. Open any workbook in Excel on the web (office.com).
  2. Home → Add-ins → More Settings (or More add-ins).
  3. Choose Upload My Add-in, browse to the file you downloaded, and select Upload.
  4. Open the Data tab → Check data.

The browser remembers it; if you clear your browser data or switch browser, upload it again.

Install in Excel for Windows (desktop)

  1. Put the downloaded file in a folder, right-click the folder → Properties → Sharing → Share, and note its network path (like \\YOUR-PC\addins).
  2. In Excel: File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs. Paste the network path, Add catalog, tick Show in Menu, OK, and restart Excel.
  3. Home → Add-ins → Advanced (or My Add-ins) → SHARED FOLDER → DataGuard → Add.

Work laptops sometimes block add-ins you install yourself. If so, use Excel on the web, or ask IT.

Using it

  1. Click any cell inside your table, then Check this table.
  2. Confirm the ID column, the date column and the totals to watch (asked once per table).
  3. Work through the Fix order tab. Every fix shows a preview, and Undo last fix puts things back.

Rules, a monthly summary and a hidden change log are saved inside the workbook so they travel with the file.
